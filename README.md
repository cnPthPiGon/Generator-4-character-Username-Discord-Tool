# Generator 4 Characters Username Discord

I'll try my best to keep everything updated and fix any bugs if I find some.

Made by Chxris & Rixer95-x2 on YouTube

Installation

First, paste this into your terminal/cmd:

git clone https://github.com/cnPthPiGon/A_DBlueD.git

Then, go inside the folder:

cd A_DBlueD

After that, install the requirements:

pip install -r requirements.txt

Version 1 – GeneratorChecker Discord

To run Version 1, just paste this into your terminal/cmd:

python GeneratorChecker.py

Version 2 – GeneratorChecker Discord

To run Version 2, paste this into your terminal/cmd:

python GeneratorCheckerV2.py
